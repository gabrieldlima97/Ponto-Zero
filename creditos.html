Fontes de dados de filmes

O Ponto Zero utiliza dados e imagens de filmes fornecidos pela API do TMDB (The Movie Database).

TMDB

This product uses the TMDB API but is not endorsed or certified by TMDB.

O Ponto Zero é um projeto independente, gratuito e sem fins comerciais. Não somos afiliados ao TMDB. Os direitos dos dados e imagens pertencem aos respectivos titulares.

Consulte os logotipos oficiais e regras de atribuição do TMDB.

Disponibilidade em serviços de streaming

As informações de disponibilidade podem ser fornecidas por JustWatch, por meio dos dados de provedores do TMDB. A disponibilidade muda conforme país, catálogo e data.

Sobre o Ponto Zero

O Ponto Zero é uma comunidade gratuita para descobrir filmes, registrar opiniões, avaliar títulos e conversar com amigos. Não possui anúncios, assinaturas, planos pagos, pagamentos ou links de afiliados.
